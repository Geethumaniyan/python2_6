# Theory Questions

## 1. What is YOLOv8?

**Answer:**

YOLOv8 (You Only Look Once Version 8) is the latest object detection model developed by Ultralytics. It is used to detect multiple objects in images and videos in a single scan. It also supports image classification, segmentation, and pose estimation. YOLOv8 is faster, more accurate, and easier to use than previous versions.

---

## 2. What is a pretrained model?

**Answer:**

A pretrained model is a machine learning model that has already been trained on a large dataset. It already knows how to recognize common objects, so users can use it directly without training it from scratch.

---

## 3. What is a confidence score?

**Answer:**

A confidence score is the probability that the detected object is correct. It is shown as a percentage. A higher confidence score means the model is more certain about its prediction.

**Example:**

* Person → 98%
* Car → 95%
* Dog → 92%

---

## 4. Why is YOLOv8 popular?

**Answer:**

YOLOv8 is popular because:

* It is very fast.
* It provides high accuracy.
* It is easy to install and use.
* It supports multiple computer vision tasks.
* It comes with pretrained models that work without additional training.

---

## 5. Difference between YOLOv8n and YOLOv8x

| YOLOv8n            | YOLOv8x                 |
| ------------------ | ----------------------- |
| Nano model         | Extra Large model       |
| Very fast          | Slower                  |
| Small model size   | Large model size        |
| Lower accuracy     | Higher accuracy         |
| Best for beginners | Best for advanced users |

# Practical Task 5

## Display Detected Objects with Confidence Scores

Replace the code with the following:

```python
from ultralytics import YOLO

# Load YOLOv8 model
model = YOLO("yolov8n.pt")

# Detect objects
results = model("image.jpg", save=True)

print("Detected Objects:")

for box in results[0].boxes:
    class_id = int(box.cls[0])
    class_name = model.names[class_id]
    confidence = float(box.conf[0])

    print(f"{class_name} -> {confidence:.2%}")
```

**Example Output:**


# Complete Python Program

```python
from ultralytics import YOLO

# Load pretrained YOLOv8 Nano model
model = YOLO("yolov8n.pt")

# Perform object detection on the image
results = model("image.jpg", save=True)

# Display detected image
results[0].show()

print("\nDetected Objects and Confidence Scores:\n")

# Print detected object names and confidence scores
for box in results[0].boxes:
    class_id = int(box.cls[0])
    class_name = model.names[class_id]
    confidence = float(box.conf[0])

    print(f"{class_name} -> {confidence:.2%}")

print("\nObject detection completed successfully!")
```
